# Лендинг «АвтоМастер» — автосервис

**Тема:** Автосервис

  https://suniiiS.github.io/landing-Zhakhansha/

## Что сделано

- Семантическая вёрстка: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<address>`, `<footer>`
- 5 смысловых блоков: hero, услуги, о нас, цены, контакты
- Иерархия заголовков: один `h1`, несколько `h2`, `h3` внутри блоков
- Форма обратной связи (имя, email, сообщение) с `<label>` для каждого поля и атрибутом `required`
- У всех изображений прописан атрибут `alt`
- В `<head>`: `title`, `meta description`, `meta viewport`, favicon
- Адаптивная вёрстка: проверено на ширине 375px и 1280px (media queries в `style.css`)
- Чистый HTML5 + CSS3, без шаблонов и конструкторов

## Файлы

- `index.html` — разметка страницы
- `style.css` — стили и адаптив
